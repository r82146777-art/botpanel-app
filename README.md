# BotPanel - پنل مدیریت ربات‌های تلگرام، روبیکا، سروش و بله

اپلیکیشن موبایل (Android) برای ساخت و مدیریت ربات‌ها **مستقیماً روی گوشی** شما.

## ویژگی‌ها

- **دو بخش اصلی**: ساخت ربات جدید + لیست ربات‌های ساخته‌شده
- انتخاب پلتفرم: تلگرام / روبیکا / سروش / بله
- توکن ربات + بررسی اعتبار
- آیدی عددی مدیران (خالی = دسترسی همه)
- کادر کد ربات (منطق ربات)
- پیام خوش‌آمدگویی (اختیاری)
- بازه زمانی فعالیت (۲۴ ساعته یا ساعت شروع/پایان)
- دکمه ذخیره و شروع
- نمایش وضعیت فعال/غیرفعال
- پشتیبان‌گیری و بازیابی کامل داده‌ها
- کار آفلاین روی گوشی (داده‌ها در حافظه محلی ذخیره می‌شود)

## ساخت APK با GitHub Actions

1. این ریپو را Fork کنید یا Push کنید.
2. به تب **Actions** بروید.
3. workflow به نام **Build APK** را اجرا کنید (Run workflow).
4. بعد از اتمام، از بخش Artifacts فایل `BotPanel-APK` را دانلود کنید.

## ساخت دستی

```bash
npm install
npm run build
npx cap sync android
# باز کردن با Android Studio و Build > Build APK(s)
```

## نکات مهم

- این اپ یک **پنل مدیریت** است. کد ربات ذخیره می‌شود و می‌توانید آن را کپی کرده و در Termux یا سرور اجرا کنید.
- برای اجرای واقعی ربات‌های طولانی‌مدت روی اندروید نیاز به سرویس پس‌زمینه دارید که در نسخه فعلی شبیه‌سازی شده است.
- داده‌ها کاملاً محلی هستند و بدون اینترنت هم کار می‌کند (به جز اعتبارسنجی توکن).
