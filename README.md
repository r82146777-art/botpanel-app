# BotPanel - پنل مدیریت ربات‌ها روی گوشی

اپلیکیشن اندروید برای ساخت و مدیریت ربات‌های تلگرام، روبیکا، سروش و بله **مستقیماً روی گوشی خودتان** (مشابه تجربه Termux).

## ویژگی‌ها
- دو بخش اصلی: ساخت ربات جدید + ربات‌های ساخته‌شده
- انتخاب پلتفرم (تلگرام / روبیکا / سروش / بله)
- توکن + آیدی مدیران + کد ربات + پیام خوش‌آمد + بازه زمانی فعالیت
- لیست ربات‌ها با وضعیت فعال/غیرفعال و دکمه تنظیمات
- پشتیبان‌گیری و بازیابی کامل
- رابط فارسی راست‌چین + کار آفلاین با localStorage

## دانلود APK
پس از push، به تب **Actions** بروید و آخرین workflow را باز کنید. Artifact به نام `botpanel-debug-apk` را دانلود کنید.

یا از Releases (اگر ساخته شود).

## ساخت محلی
```bash
npm install
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```
