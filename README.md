# BotPanel App

پنل ساخت و مدیریت ربات برای تلگرام، روبیکا، سروش و بله.

## ویژگی‌های اضافه‌شده

- انتخاب پلتفرم (تلگرام / روبیکا / سروش / بله)
- توکن ربات
- آیدی عددی مدیران (خالی = همه)
- کادر کد ربات
- پیام خوش‌آمدگویی اختیاری
- بازه زمانی فعالیت (۲۴ساعته یا شروع/پایان)
- دکمه ذخیره و شروع
- لیست ربات‌های ساخته‌شده با وضعیت فعال/غیرفعال و دکمه تنظیمات
- پشتیبان‌گیری و بازیابی کامل

## ساخت

```bash
npm install
npm run build
npx cap sync android
# سپس در Android Studio بیلد APK بگیرید
```

سورس کامل در فایل zip تحویل داده شده است.
